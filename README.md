A small Python program that writes one sentence, under 200 characters, to `/output/entry.txt`. The sentence explains the modern internet to someone who has just arrived from 1800. It uses a picture they already know: a single post office serving the whole world, whose clerks run on lightning, so a letter reaches China in a heartbeat and the same counter also lends books, sells goods and carries your voice.

## Run it

```sh
python3 main.py
```
